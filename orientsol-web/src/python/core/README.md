# Solar Geometry Core Module (`core/`)

This module will contain functions for solar geometry:
- `matriz_declinacion.m` -> `declination.py`: Monthly solar declination angle ($\delta$) for characteristic days.
- `AngulosSalida.m` -> `sunset_angle.py`: Sunset and sunrise hour angles ($\omega_s$).
- `Angulos.m` & `Angulos2.m` -> `hour_angles.py`: Discretization of daylight hours into angular intervals.
- `Altura_Solar.m` -> `solar_altitude.py`: Solar elevation angle ($\alpha_s$).
- `Azimut_Solar.m` -> `solar_azimuth.py`: Solar azimuth angle ($\psi_s$).
